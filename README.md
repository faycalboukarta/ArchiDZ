# ArchiDZ - الهندسة المعمارية

A modern, fully responsive landing page for an architectural bureau, built with HTML, CSS, and Vanilla JavaScript. The design features a premium aesthetic tailored for Arabic Right-to-Left (RTL) reading direction.

## Features

- **Pixel-Perfect Design**: Follows a premium architectural UI design with elegant color schemes (Dark Blue & Gold).
- **Fully Responsive**: Adapts seamlessly to Desktop, Tablet, and Mobile screens using modern CSS Grid and Flexbox layouts.
- **RTL Support**: Native Arabic Right-to-Left formatting.
- **Interactive Elements**: Includes a smooth mobile hamburger menu toggle, interactive CSS hover states, and a testimonial slider.
- **Modern Typography**: Uses the "Cairo" Google Font for clean and professional Arabic text rendering.
- **Zero Dependencies**: Lightweight architecture built with pure HTML, CSS, and JavaScript. (FontAwesome is used via CDN for icons).

## Technologies Used

- **HTML5**: Semantic and accessible markup.
- **CSS3**: Custom properties (variables), Grid, Flexbox, and media queries for responsiveness.
- **Vanilla JS**: Lightweight scripting for DOM manipulation and slider logic.
